# AI Voice Assistant

AI Voice Assistant using Machine Learning and Natural Language Processing for speech recognition, intent prediction, and task automation through an interactive Streamlit dashboard.

## Features

- Voice Commands
- Text Commands
- Speech Recognition (Whisper)
- Intent Prediction
- Streamlit Dashboard
- Command History
- Open Applications
- Google Search

## Technologies Used

- Python
- Streamlit
- Scikit-Learn
- OpenAI Whisper
- FFmpeg
- Pandas
- NumPy

## Run Project

```bash
pip install -r requirements.txt
streamlit run gui/dashboard.py
```
